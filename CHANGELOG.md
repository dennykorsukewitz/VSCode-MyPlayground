# Changelog

All notable changes to the "MyPlayground" extension will be documented in this file.

## [1.0.0]

### Added

- Sidebar for small games. **Scores** lists every game. Each game links to that list. A best score stays in extension global state on this machine.
- First game: Snake. Arrow keys, WASD, and on-screen buttons steer.
- The run speeds up every four snacks and ends on a wall, the snake, or a full board.

### Changed

- Removed the outline stub.
